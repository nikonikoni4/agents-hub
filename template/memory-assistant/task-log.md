# 任务日志编写规范

## 写入位置

追加到 `{data_path}/schedule/memory/agents_hub_history/history.jsonl`，每行一条 JSON 记录。

## 记录格式

```json
{
  "group_chat_id": "群聊ID",
  "timestamp": "ISO 8601 时间戳",
  "summary": "任务总结内容"
}
```

## 总结要求

依据群聊的历史信息和最新消息，对当前执行的任务进行总结，包括：

1. **任务背景** — 为什么做这个任务
2. **任务描述** — 具体要做什么
3. **执行情况** — 过程中的关键节点
4. **任务结果** — 最终产出和状态

## 约束

- 每条总结不超过 200 字
- history.jsonl 保留最近 1000 条记录，超出时删除最早的记录
- 如果群聊在上次更新后没有新的任务活动，跳过不写
