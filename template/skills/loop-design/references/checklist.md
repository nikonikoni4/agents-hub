# Loop 设计快速检查清单

## 需求澄清阶段

- [ ] 问题定义清晰
- [ ] 参与角色明确
- [ ] 退出条件确定
- [ ] 预期轮数合理
- [ ] 特殊约束已记录

## 节点流程设计阶段

- [ ] 节点数量 >= 2
- [ ] 有且仅有 1 个 TERMINATOR 节点
- [ ] 每个节点职责清晰、不重叠
- [ ] 数据流转路径明确
- [ ] 用户已确认节点流程

## 提示词设计阶段

### role_description 检查

- [ ] 明确节点在循环中的职责
- [ ] 说明输入来源
- [ ] 说明输出目标
- [ ] 不与 Agent role 描述冲突
- [ ] 无歧义、无模糊表述

### output_schema_prompt 检查

- [ ] 使用 Markdown 格式
- [ ] 包含清晰的标题
- [ ] 有填写说明
- [ ] 格式易于执行

### output_schema_fields 检查

- [ ] 与 output_schema_prompt 标题完全一致
- [ ] 字段名称准确
- [ ] 包含所有必需字段

## 上下游配合检查

- [ ] 上游输出满足下游输入需求
- [ ] 数据格式匹配
- [ ] 信息无缺失

## Subagent 验证阶段

- [ ] 所有节点已验证
- [ ] 职责清晰度通过
- [ ] 输入充分性通过
- [ ] 输出可执行性通过
- [ ] 上下游配合通过

## 用户确认阶段

- [ ] 用户已确认节点流程
- [ ] 用户已确认提示词

## 创建循环阶段

- [ ] 调用 create_loop 成功
- [ ] 返回 loop_id
- [ ] 询问用户是否启动

## 常见问题检查

### 提示词问题

- ❌ role_description 与 Agent role 冲突
- ❌ output_schema_prompt 格式不清晰
- ❌ output_schema_fields 与 prompt 不一致
- ❌ 职责描述模糊

### 流程问题

- [ ] 缺少需求澄清环节
- [ ] 缺少用户确认环节
- [ ] 缺少 Subagent 验证
- [ ] 节点流程设计不合理

### 配合问题

- [ ] 上下游数据格式不匹配
- [ ] 信息传递有缺失
- [ ] 退出条件不明确
