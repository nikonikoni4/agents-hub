# 节点设计模板

## 使用说明

为循环中的每个节点填写此模板，确保节点设计完整、清晰。

## 节点设计模板

```markdown
## 节点: {节点名称}

### 基本信息

- **节点类型**: normal / terminator
- **执行 Agent**: {agent_name}

### 职责定位

- **在这个循环中我要做什么**: {具体职责描述}
- **我的核心任务**: {任务简述}

### 输入分析

- **我需要接收什么信息**: {需要的信息}
- **上游节点会给我什么**: {上游输出内容}
- **输入格式要求**: {格式说明}

### 输出定义

- **我需要输出什么**: {输出内容}
- **输出格式要求** (output_schema_prompt):

```markdown
请按以下格式输出：

## {标题1}
（{填写说明}）

## {标题2}
（{填写说明}）
```

- **必需字段** (output_schema_fields):
  - `{标题1}`
  - `{标题2}`

### 质量标准

- **什么样的输出是合格的**:
  - {合格标准1}
  - {合格标准2}

- **什么样的输出需要重试**:
  - {重试条件1}
  - {重试条件2}
```

## 填写示例

### 示例 1: Executor 节点

```markdown
## 节点: executor

### 基本信息

- **节点类型**: normal
- **执行 Agent**: executor

### 职责定位

- **在这个循环中我要做什么**: 根据审查反馈修改代码
- **我的核心任务**: 代码实现和修改

### 输入分析

- **我需要接收什么信息**: 审查意见和修改建议
- **上游节点会给我什么**: Reviewer 的审查反馈
- **输入格式要求**: Markdown 格式的审查意见

### 输出定义

- **我需要输出什么**: 修改后的代码和修改说明
- **输出格式要求** (output_schema_prompt):

```markdown
请按以下格式输出：

## 实现代码
（粘贴修改后的代码）

## 修改说明
（说明本次修改了哪些内容，为什么这样修改）
```

- **必需字段** (output_schema_fields):
  - `## 实现代码`
  - `## 修改说明`

### 质量标准

- **什么样的输出是合格的**:
  - 代码能正常运行
  - 修改说明清晰
  - 包含所有必需字段

- **什么样的输出需要重试**:
  - 缺少必需字段
  - 代码有明显语法错误
  - 修改说明为空
```

### 示例 2: Reviewer 节点 (terminator)

```markdown
## 节点: reviewer

### 基本信息

- **节点类型**: terminator
- **执行 Agent**: reviewer

### 职责定位

- **在这个循环中我要做什么**: 审查代码质量，判断是否通过
- **我的核心任务**: 代码审查和质量判断

### 输入分析

- **我需要接收什么信息**: 实现的代码
- **上游节点会给我什么**: Executor 的代码输出
- **输入格式要求**: Markdown 格式的代码

### 输出定义

- **我需要输出什么**: 审查意见和结论
- **输出格式要求** (output_schema_prompt):

```markdown
请按以下格式输出：

## 审查意见
（详细说明审查结果）

## 审查结论
（填写"通过"或"需修改"）
```

- **必需字段** (output_schema_fields):
  - `## 审查意见`
  - `## 审查结论`

### 质量标准

- **什么样的输出是合格的**:
  - 审查意见详细
  - 审查结论明确（通过/需修改）
  - 包含所有必需字段

- **什么样的输出需要重试**:
  - 缺少必需字段
  - 审查结论不明确
  - 审查意见为空
```

## 填写要点

### 职责定位

- ✅ 明确说明"在这个循环中我要做什么"
- ✅ 与 Agent 本身的 role 描述不冲突
- ❌ 重复 Agent 的角色定义
- ❌ 职责描述模糊

### 输入分析

- ✅ 明确说明需要什么信息
- ✅ 说明上游节点的输出
- ❌ 假设执行者已有上下文
- ❌ 输入信息不完整

### 输出定义

- ✅ output_schema_prompt 使用 Markdown 格式
- ✅ output_schema_fields 与 prompt 标题一致
- ❌ 格式要求模糊
- ❌ 字段定义不明确

### 质量标准

- ✅ 合格标准明确
- ✅ 重试条件清晰
- ❌ 标准模糊
- ❌ 没有重试条件
