## 示例 1：视频剪辑 Agent（创建流程）

### 用户初始请求

```
用户："我想创建一个视频剪辑 Agent，但我不懂剪辑。"
```

---

### Stage 1: 训练模式选择

```
Agent: "我会帮你创建视频剪辑 Agent。首先确认训练模式：

**模式 A：通用领域 Agent**
- 适用于多个项目的通用剪辑助手
- 学习通用的剪辑最佳实践

**模式 B：项目专用 Agent**
- 绑定到特定项目（如你的 YouTube 频道）
- 学习项目风格 + 通用最佳实践

你想要哪种模式？"

用户："模式 A，通用的就行。"
```

---

### Stage 2: Agent 角色定义

```
Agent: "好的。让我们定义这个 Agent 的角色。我需要了解：

1. **视频类型**？
   - YouTube 教程
   - 短视频（TikTok/抖音）
   - 纪录片风格
   - Vlog
   - 其他？

2. **Agent 应该做什么**？
   - 建议剪辑点
   - 推荐转场
   - 优化节奏
   - 识别技术问题
   - 其他？

3. **不应该做什么**？
   - 最终创意决策
   - 音频混音
   - 动效制作
   - 其他？

4. **使用者**？
   - 你作为新手
   - 与其他人协作
   - 给客户使用

5. **平台**？
   - Codex
   - Claude Code
   - OpenCode"

用户："YouTube 教程，帮我建议剪辑点、推荐转场、识别问题。不做创意决策和音频混音。我是新手。用 Codex。"
```

---

### 角色定义确认

```
Agent: "理解如下：

**Agent 角色定义**
- Agent 名称: 视频剪辑助手
- 平台: Codex
- 领域: YouTube 教程视频剪辑
- 核心职责:
  - 基于节奏最佳实践建议剪辑点
  - 推荐保持流畅的转场方式
  - 识别技术问题（光线、音频同步）
- 边界:
  - 最终创意方向由用户决定
  - 音频混音/母带处理
  - 动态图形创作
- 协作对象: 你（剪辑新手）学习剪辑基础
- 成功标准: 输出流畅、技术质量过关、教学效果好的教程视频

这符合你的需求吗？"

用户："是的。"
```

---

### Stage 4: 知识需求分析

```
Agent: "好的。对于 YouTube 教程视频剪辑 Agent，我会搜索：

**元规则**：
- 执行前确认：理解视频目的、目标观众、时长要求
- 决策风格：保守 vs 实验性剪辑
- 执行后自检：节奏、连贯性、技术质量

**领域知识**：
- 教程视频节奏最佳实践
- 转场选择指南
- 常见新手错误
- 技术规范（分辨率、帧率等）

开始搜索..."
```

---

### Stage 5: 搜索并评估

```
Agent: [执行搜索]

[第 1 轮搜索]
"正在搜索：教程视频剪辑最佳实践..."

[第 2 轮搜索]
"正在搜索：视频转场技巧、常见剪辑错误..."

"搜索完成。发现：

**高质量来源**（Tier A/B）：
- YouTube Creator Academy（官方指南）
- Adobe Premiere 官方教程
- 专业剪辑师博客（3 篇）
- 行业会议演讲（2 个）

**参考来源**（Tier C）：
- 社区讨论（12 条）
- 个人经验分享（8 篇）

**信息缺口**：
- 调色标准（未找到教程视频的权威来源）

进入规则提取..."
```

---

### Stage 6: 元规则提取与确认

```
Agent: "基于搜索结果，提取了以下元规则和知识：

---

**元规则（将写入 AGENTS.md）**

### 执行前 Checklist
- [ ] 理解视频目的：教学目标是什么？
- [ ] 确认观众：新手 vs 有经验的观众？
- [ ] 时长约束：目标时长？平台限制？
- [ ] 确认项目技术约束：导出格式、分辨率、帧率

### 决策风格
- 优先简单剪辑，避免花哨转场干扰教学内容
- 不确定时询问用户创意偏好
- 技术问题（音频同步、曝光）必须指出

### 执行后自检
- [ ] 节奏检查：演示是否流畅？关键点是否强调？
- [ ] 连贯性：转场是否自然？音频是否匹配？
- [ ] 技术质量：画面清晰、音频清晰、字幕可读？

---

**领域知识（将放入 knowledge/）**

### 基础知识
- 视频格式：1080p 最低，H.264 编码
- 帧率：24fps（电影感）vs 60fps（流畅演示）
- 音频：立体声，-14 LUFS 标准

### 最佳实践
- 教程节奏：演示 1.5-2x 速度，重点慢讲
- 转场使用：每个视频限制 2-3 种类型保持一致性
- 开场：前 10 秒用问题陈述吸引观众
- L-cut 和 J-cut：对话转场更自然

### 常见陷阱
- 跳切过密（0.5s 内产生突兀感）
- 过度使用特效（分散注意力）
- 背景音乐过大（压过解说）
- 字幕缺失或不可读

---

**信息缺口**：
- 调色标准（只找到通用建议，无教程视频权威标准）

批准这些规则？有需要调整的吗？"

用户："是的，但加一条：视频不超过 15 分钟。"
```

---

### 规则更新

```
Agent: "已添加到执行前 Checklist：
- [ ] 时长约束：目标时长？平台限制？（教程最佳长度 10-15 分钟）

正在生成训练文件..."
```

---

### Stage 7: 生成文件

```
Agent: "训练完成！已创建以下文件：

**生成的文件**：
- `work_root/AGENTS.md`
  - 角色定位
  - 执行前 Checklist
  - 决策风格
  - 执行后自检
  - 知识库链接

- `work_root/knowledge/fundamentals.md`
  - 视频格式基础
  - 技术规范
  - 工具使用

- `work_root/knowledge/best-practices.md`
  - 教程视频节奏
  - 转场技巧
  - 开场设计
  - L-cut 和 J-cut

- `work_root/knowledge/pitfalls.md`
  - 跳切问题
  - 特效滥用
  - 音频问题
  - 字幕问题

- `work_root/.training-metadata.json`
  - 训练元数据

---

**训练总结**：
- **元规则**：3 类（执行前/决策/执行后）
- **知识覆盖**：基础技术、最佳实践、常见错误
- **已知局限**：调色标准（缺少权威来源）

---

**建议测试**：
让它审查一段粗剪素材，看它能否：
1. 指出技术问题（音频、画质）
2. 建议剪辑点
3. 推荐转场方式

你的视频剪辑助手已就绪！"
```

## 使用提示

### 如何使用这些示例

1. **参考交互模式**：了解每个阶段的对话方式
2. **调整领域内容**：替换为你的具体领域
3. **保持用户确认**：关键阶段必须获得用户批准
4. **展示价值**：让用户看到搜索结果和提取的规则

### 常见变体

**快速模式**（用户很明确）：
- 可以跳过某些询问
- 直接展示角色定义让用户确认

**详细模式**（用户不确定）：
- 每个选择都提供更多解释
- 展示更多示例帮助决策
