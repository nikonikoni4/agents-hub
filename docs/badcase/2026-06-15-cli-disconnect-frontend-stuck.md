# CLI 断开导致前端卡住的体验问题

## 版本

| 版本 | 更新内容 |
| ---- | -------- |
| 1.0 | 创建文档初稿 |

## 问题描述

当 CLI 在运行过程中因各种外部原因断开时，前端会直接停止或卡住，导致用户失去对运行过程的掌控感。

## 问题场景

1. **高并发导致模型限流**：当多个用户同时使用时，模型服务可能返回限流错误
2. **网络波动**：网络不稳定导致连接中断
3. **服务端异常**：后端服务临时故障或重启
4. **超时**：长时间运行的任务超时

## 问题表现

- 前端界面完全卡住，无任何反馈
- 用户无法知道当前状态（是否还在运行、是否已失败）
- 无法进行重试或恢复操作
- 需要手动刷新页面才能继续

## 影响

- 用户体验差，失去掌控感
- 无法区分"正在思考"和"已经失败"
- 重试成本高，需要重新开始整个流程

## 优化方向

1. **状态可见性**：实时展示 CLI 连接状态和运行状态
2. **错误反馈**：明确告知用户发生了什么错误
3. **重试机制**：提供自动重试或手动重试选项
4. **优雅降级**：断开时保留已生成内容，支持断点续传
5. **心跳检测**：定期检测连接状态，及时发现断开

## 优先级

**高** - 直接影响用户使用体验和平台可信度
