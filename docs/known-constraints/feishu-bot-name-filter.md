# 飞书 @bot_name 过滤已知局限

**文档版本**: 1.0
**创建日期**: 2026-06-28
**适用范围**: `agents_hub/channels/feishu/channel.py` on_message() 中的 @bot_name 过滤

---

## 1. 仅匹配行首

**限制内容**：
- `@bot_name` 过滤仅处理消息字符串最开头的 `@机器人名`
- 正则 `^@?\s*{bot_name}\s+` 使用 `^` 锚点，限定匹配位置

**理由**：
- 避免误删消息正文中出现的机器人名字（如用户提到"让飞书助手来处理"）
- 移除 `^` 会导致 `re.escape(bot_name)` 匹配正文中任何位置的机器人名字，可能损坏消息语义

**影响**：

| 消息内容 | 能否过滤 | 说明 |
|---------|---------|------|
| `@飞书助手 帮我创建单聊` | ✅ | 机器人在行首 |
| `你好 @飞书助手 创建单聊` | ❌ | 前面有"你好 " |
| `@张三 @飞书助手 看看` | ❌ | 前面有 @张三  |

**缓解方案**：
- 飞书群聊中，@机器人通常被飞书客户端放置在消息开头
- `config.bot_names` 可配置多个机器人名称，逐一尝试匹配
